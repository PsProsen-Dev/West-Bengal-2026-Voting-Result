# West Bengal 2026 Voting Result

Official Election Commission of India result dashboard for West Bengal party-wise results.

## Data source

This project intentionally uses only the official ECI West Bengal result page:

```txt
https://results.eci.gov.in/ResultAcGenMay2026/partywiseresult-S25.htm
```

- State: West Bengal
- ECI state code: S25
- Third-party sources: not used
- Cached/generated fallback results: not used

If the official ECI page is unreachable or changes its markup, the app shows an error instead of showing guessed or third-party data.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

The app is ready for Vercel. Import this GitHub repository into Vercel or use the Vercel CLI.
